# Configuration

puppenclaw reads one JSON configuration object and a set of environment variables. The object configures the OpenClaw
plugin (`plugins.entries.puppenclaw.config`) and the daemon (`--config <file>`) alike; `openclaw.plugin.json` carries
the same schema, regenerated by `npm run build`. The daemon reads environment variables for everything that is
specific to one deployment: providers, broker limits, maintenance and the compute sandbox.

## Configuration object

Every level is strict, so an unknown key fails validation; only the entries of `mcpServers` keep any field.

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `backend` | `local` or `daemon` | `local` | Plugin only. `local` runs agents in the plugin process; `daemon` sends every call to `daemonUrl`. |
| `daemonUrl` | string | `http://127.0.0.1:18795` | Plugin only. |
| `daemonAuthToken` | string | unset | Bearer token. The daemon requires it on every route except `GET /health` and `GET /capabilities`; the plugin and `puppenclaw-daemon stop` send it. Empty means no authentication. |
| `defaultAgent` | `claude` or `codex` | `claude` | Agent of sessions that name none. |
| `maxSessions` | positive integer | `5` | Persistent agent runtimes admitted at once. Idle, unfocused runtimes may be suspended to admit new work; retained history and one-shot Codex sessions do not count. When every slot is active or focused, a new runtime is refused with `MAX_SESSIONS_REACHED`. |
| `permissionMode` | `approve-reads`, `approve-all`, `deny-all` | `approve-reads` | Permission policy of agent tools. A turn may request another mode unless this is `deny-all`. |
| `sessionTtlMinutes` | 1–1440 | `60` | Garbage collection purges failed and stopped sessions idle for longer than this (the plugin every minute, the daemon on `POST /gc`). Idle, waiting and suspended sessions are never collected, nor is a session with a running turn. |
| `streamOutput` | boolean | `true` | Accepted and reported as `streamOutput` in `GET /capabilities` and in site status; output capture and streaming do not depend on it. |
| `resourceSamplingIntervalMs` | 5000–600000 | `30000` | Interval of the daemon's `/proc` resource samples. |
| `resourceRetentionDays` | 1–90 | `7` | Days of resource history kept in `resources/resources.sqlite`. |
| `acpxCommand` | string | `acpx` | The ACP launcher. |
| `codexCommand` | string | unset | Launcher wrapped around provider Codex turns: the daemon runs `<codexCommand> --cwd <dir> -- <codex launcher> exec …` instead of the codex launcher itself. |
| `skillRoots` | string array | `[]` | Extra directories of Claude Code skills, each `<root>/<skill>/SKILL.md`. Sessions can install named skills (`skills` on `POST /session/start`); `GET /skills` lists them. |
| `agentCommands.claude` | string | unset | Raw ACP adapter command for Claude, passed to acpx as `--agent`. Without it acpx starts its own adapter for the `claude` alias. |
| `agentCommands.codex` | string | unset | Raw ACP adapter command for Codex sessions without a model provider (passed as `--agent`), and the launcher of the `codex` CLI for Codex sessions with a model provider (default `codex`). |
| `mcpServers` | object | `{}` | MCP server definitions (`command`, `args`, `env`, `cwd`, `url`, …). puppenclaw records them and warns at session start; injecting them is up to the agent command. |
| `fallbackTarget` | string | unset | Accepted by the schema; the current code does not read it. |
| `remoteControl.purePipe.enabled` | boolean | `false` | Allow deterministic `/puppenclaw` control from remote `oc2oc` conversations that were bound and exposed (see [the plugin guide](openclaw-plugin.md#oc2oc-remote-control)). |
| `remoteControl.mediated.enabled`, `remoteControl.purePipe.allowFrom`, `remoteControl.purePipe.allowedAgents`, `remoteControl.requireConversationBinding` | | `true`, `[]`, `[]`, `true` | Accepted by the schema; the current code does not read them. Agents and verbs are exposed per binding with `/puppenclaw expose`, and pure-pipe control always requires a bound conversation. |
| `orchestration.enabled` | boolean | `true` | Enable projects and campaigns. |
| `orchestration.maxCampaigns` | 1–500 | `32` | Campaigns that may be active (`draft`, `running`, `waiting_approval`, `cancelling`, `recovery_required`) at once. |
| `orchestration.artifactRetentionHours` | 1–8760 | `336` | Artifacts of finished campaigns older than this are pruned when the runtime is used; artifacts of running or waiting campaigns are kept. |
| `orchestration.allowLocalCommandExecution` | boolean | `true` | Allow `command` steps and the built-in evaluation and experiment commands. |
| `orchestration.defaultProjectRoot` | string | unset | Base directory for relative project `rootDir` values; also a workspace root for compute jobs. |
| `orchestration.gptResearcherCommand` | string | unset | Shell command for `research` steps: receives the step prompt on stdin, returns a dossier on stdout. |
| `orchestration.fusionArbiterCommand` | string | unset | Command that receives the fusion dossier of a `puppenfusion` campaign that sets `useExternalArbiter`. |
| `orchestration.localWorker.id` | string | `local` | Id of the built-in worker. |
| `orchestration.localWorker.label` | string | `Local Worker` | Its label. |
| `orchestration.localWorker.labels` | string array | `["local"]` | Its labels. |
| `orchestration.localWorker.projectRoots` | string array | `[]` | Roots the built-in worker may operate in; also workspace roots for compute jobs. |

### How agents are started

Claude sessions, and Codex sessions without a model provider, run through acpx and an ACP adapter:

```text
caller -> puppenclaw -> acpx -> claude-agent-acp or codex-acp
```

`acpxCommand` is the launcher; `agentCommands` only replaces the adapter that acpx starts. The adapters run with the
daemon's (or the OpenClaw gateway's) `HOME`, `PATH` and credentials: every agent process, and every codex launcher,
inherits the daemon's whole environment plus the variables
[listed below](#variables-the-daemon-sets-for-child-processes). Run puppenclaw under a dedicated `HOME` that holds the
agents' logins, or wrap an adapter command with `env HOME=… ` when it should use another account. Before blaming
puppenclaw for a failing agent, run the same acpx command by hand with the same `HOME` and working directory;
[the plugin guide](openclaw-plugin.md#acp-verification) lists the commands.

A Codex session with a `modelProvider` runs `codex exec --json` once per turn instead (through `codexCommand` when
set). The approval mode maps onto Codex's own flags: `approve-reads` runs with `--sandbox read-only`, `approve-all`
with `--dangerously-bypass-approvals-and-sandbox`, which a deployment must confine in its own sandbox. Codex has no
deny-all flag: `deny-all` uses the read-only sandbox and adds an instruction not to use tools, which is a safeguard,
not a hard boundary. The turn process receives the provider's settings as `PUPPENCLAW_MODEL_PROVIDER_*` variables
([below](#variables-the-daemon-sets-for-child-processes)), so the codex launcher can be a wrapper that configures Codex
for that provider; this repository ships no such wrapper. Codex writes its final message to a file under
`.puppenclaw/tmp/` in the session directory, which the daemon reads and deletes when the turn ends; the directory itself
stays.

### Model providers

A turn may name a model provider (`modelProvider`) with this shape, which `PUPPENCLAW_MODEL_PROVIDERS` uses as well:

| Field | Meaning |
| --- | --- |
| `id` | Provider id (`A-Za-z0-9._-`). |
| `label` | Display label. |
| `kind` | `claude-code`, `codex-openai` or `codex-openai-compatible`. |
| `model` | Model name. |
| `reasoningProfile` | `claude`, `codex`, `glm-5.2`, `qwen-3.6` or `qwen-3.8`; otherwise derived from the model name and the agent. |
| `baseUrl` | Endpoint. Without one, the broker addresses `https://api.anthropic.com` for `claude-code`, the ChatGPT Codex backend for `codex-openai` and `https://api.openai.com/v1` for `codex-openai-compatible`. |
| `authTokenEnv` | Name of the daemon environment variable that holds the API key; never the key itself. |
| `wireApi` | `responses`. |
| `subagents` | Codex local subagent policy, see below; only for `codex-openai-compatible`. |

**Reasoning effort.** Turns accept `effort` from `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`,
`ultra` and `ultracode`, resolved per provider profile. `GET /capabilities` publishes each profile's modes and aliases
under `reasoning`; a value outside a profile is refused with `UNSUPPORTED_REASONING_MODE` before the turn starts.
Claude `ultra` maps to `max` with a warning. Claude `ultracode` runs `xhigh` effort with the adapter's native workflow
orchestration, enabled through the ACP config option `ocsl_workflow_v1`; an adapter that does not accept that option
fails the turn with `UNAVAILABLE_REASONING_MODE` before any prompt is sent, and Ultracode never falls back to Max.

**Codex local subagent policy.** A `codex-openai-compatible` provider may carry
`"subagents": {"model": "chat", "effort": "xhigh", "maxConcurrentThreads": 6}` (`maxConcurrentThreads` 1–16). The
policy is persisted with the session, copied by forks and part of the turn fingerprint only when present. With a
policy, a provider Codex turn passes `PUPPENCLAW_MODEL_PROVIDER_SUBAGENT_MODEL`, `_SUBAGENT_EFFORT`,
`_SUBAGENT_MAX_THREADS` and the main turn's effort as `PUPPENCLAW_MODEL_PROVIDER_REASONING_EFFORT` to the provider
wrapper and omits the `-m` and `-c model_reasoning_effort` overrides, because the wrapper writes the main model and
effort into Codex's `config.toml` next to the pinned subagent roles. A session model that differs from the provider's
model fails with `MODEL_PROVIDER_SUBAGENT_POLICY_CONFLICT`. The daemon never forwards these variables from its own
environment. Daemons that support the policy advertise
`codexLocalSubagents: {"version": 1, "modelProviderField": "subagents", "cliModelOverrides": false}` on
`GET /capabilities`; daemons without it refuse the field.

## Environment variables

Settings marked *fails startup* stop the daemon when their value is invalid; the others fall back to their default.

### Daemon

| Variable | Default | Meaning |
| --- | --- | --- |
| `PUPPENCLAW_BUILD_ID` | package version and bundle digest | Build id reported by `/v2/health` and `/v2/capabilities`: 1–128 characters of `A-Za-z0-9._+:-`, otherwise `<version>+<first 12 hex of the bundle's sha256>`. |
| `PUPPENCLAW_SHUTDOWN_TIMEOUT_MS` | `20000` | Longest graceful shutdown; at least 1000. |
| `PUPPENCLAW_BOOT_REAPER` | `observe` | Leftover agent process groups of a crashed daemon: `observe` counts them, `on` terminates those whose leader is provably the recorded process, `off` keeps no records. |
| `PUPPENCLAW_ACTIVE_TURN_CHECKPOINT_MS` | `30000` | How often live-turn progress is persisted, for all turns together; at least 250. Status reads report live values. |
| `PUPPENCLAW_SSE_MAX_PENDING_BYTES` | `8388608` | Per-stream queue of a slow SSE client before progress events are dropped; at least 65536. |

### Broker

| Variable | Default | Meaning |
| --- | --- | --- |
| `PUPPENCLAW_MODEL_PROVIDERS` | unset | JSON array (up to 256) of model provider configurations, unique by id. The only source of a principal provider's endpoint, model and credential variable. *Fails startup.* |
| `PUPPENCLAW_ONPREM_PROVIDERS` | unset | JSON array of provider ids that count as on premises; each must be configured in `PUPPENCLAW_MODEL_PROVIDERS` with a valid `baseUrl`. Unset means none, so restricted evidence policies are refused. *Fails startup.* |
| `PUPPENCLAW_WORKER_POLICY` | `on` | `off` advertises no worker policy and refuses every worker policy field with `WORKER_POLICY_DISABLED`. *Fails startup.* |
| `PUPPENCLAW_LEGACY_ATTEMPT_AUTHORITY` | `on` | `on`: an `execute` turn with `approve-all` may submit bulk work over its turn socket. `off`: only run principals carry bulk authority. *Fails startup.* |
| `PUPPENCLAW_BULK_PROVIDER_CONCURRENCY` | `60` | Default limit of bulk calls in flight per provider; a positive safe integer. *Fails startup.* |
| `PUPPENCLAW_BULK_PROVIDER_LIMITS` | `{}` | JSON object of per-provider limits, for example `{"llm-high": 40}`. *Fails startup.* |
| `PUPPENCLAW_BULK_PROVIDER_GROUPS` | `{}` | JSON object mapping provider ids to capacity groups; members share one pool. *Fails startup.* |
| `PUPPENCLAW_BULK_GROUP_LIMITS` | `{}` | JSON object of explicit group limits; a group must have members. *Fails startup.* |
| `PUPPENCLAW_BULK_RESPONSE_TIMEOUT_MS` | `1800000` | Deadline of each bulk call after admission, headers and body; 1–86400000. *Fails startup.* |
| `PUPPENCLAW_BULK_RETRY_ATTEMPTS` | `3` | Attempts per bulk item for transient failures; 1–10. *Fails startup.* |
| `PUPPENCLAW_BULK_RETRY_BASE_MS` | `1000` | Base of the exponential backoff (±20 % jitter, at most 30 s); 0–60000. *Fails startup.* |
| `PUPPENCLAW_BULK_DIRECT_UPSTREAMS` | unset | JSON object mapping a registered provider base URL to the upstream behind it, for tool-free bulk calls (see [broker](broker.md#direct-upstreams)). URLs are http(s) without credentials, query or fragment. *Fails startup.* |
| `PUPPENCLAW_ADVANCED_COMMIT_WINDOW_MS` | `50` | Group-commit window of the broker store; 0–50. *Fails startup.* |
| `PUPPENCLAW_SUBMISSION_DIGESTS` | `worker` | `worker` computes bulk submission digests on a worker thread, `inline` on the event loop; both give the same values. *Fails startup.* |
| `PUPPENCLAW_EVENT_RETENTION_DAYS` | off | Hourly, delete acknowledged feed events older than this; 7–36500. Unacknowledged events are never deleted. *Fails startup.* |
| `PUPPENCLAW_ADVANCED_ARCHIVE_DAYS` | off | Daily, move eligible terminal broker jobs older than this to a verified archive; 30–36500 (see [operations](operations.md#archiving-broker-jobs)). *Fails startup.* |

### Compute jobs

| Variable | Default | Meaning |
| --- | --- | --- |
| `PUPPENCLAW_COMPUTE_SANDBOX_WRAPPER` | unset | Absolute path of the trusted launcher (a Node script run with the daemon's Node). Required for compute jobs. |
| `LAB_SANDBOX_CONFIG` | unset | Absolute path of the sandbox policy (JSON with `mode: "bubblewrap"` and an absolute `workspaceRoot`, optionally under a `sandbox` key). Required for compute jobs. |
| `PUPPENCLAW_ROOTLESS_DOCKER_PROBE_IMAGE` | `alpine:3.20` | Image of the rootless Docker probe in `GET /compute/capacity`. |

### Codex and the plugin

| Variable | Meaning |
| --- | --- |
| `PUPPENCLAW_DIRECT_CODEX_AGENT_COMMAND`, `CODEX_EXECUTABLE` | The real Codex binary for a provider wrapper: the daemon passes `PUPPENCLAW_DIRECT_CODEX_AGENT_COMMAND` (its own value, else `CODEX_EXECUTABLE`, else `codex`) to provider Codex turns. |
| `OPENCLAW_STATE_DIR` | Plugin state directory when the OpenClaw host provides none; otherwise `.puppenclaw` under the working directory. |

### Variables the daemon sets for child processes

| Process | Variables |
| --- | --- |
| Turns of a session with a model provider | `PUPPENCLAW_MODEL_PROVIDER_ID`, `_MODEL`, `_LABEL`, `_KIND`, `_BASE_URL`, `_AUTH_TOKEN_ENV`, `_WIRE_API`, `_REASONING_PROFILE`, and with a subagent policy `_SUBAGENT_MODEL`, `_SUBAGENT_EFFORT`, `_SUBAGENT_MAX_THREADS`, `_REASONING_EFFORT` |
| Provider Codex turns | `PUPPENCLAW_CODEX_TURN_POLICY` (`default`, `plan-no-tools`, `plan-read-tools`, `execute-tools`, `deny-all-no-tools`), derived from the turn's interaction and permission mode only, and `PUPPENCLAW_DIRECT_CODEX_AGENT_COMMAND` |
| Orchestrated turns and agent jobs | `PUPPENCLAW_ORCHESTRATION_SOCKET`, `PUPPENCLAW_ORCHESTRATION_NATIVE_BASE_PATH` (`/native`), `PUPPENCLAW_ORCHESTRATION_ATTEMPT_ID`, `PUPPENCLAW_ORCHESTRATION_JOB_ID` (agent jobs), for Claude Code `PUPPENCLAW_ORCHESTRATION_CLAUDE_OAUTH_CERT` and `ANTHROPIC_DEFAULT_HAIKU_MODEL`, for other providers that process's own provider `authTokenEnv` set to a placeholder; every other variable of the daemon environment, other providers' keys included, passes through |
| Campaign `research` commands | `PUPPENCLAW_PROJECT_ID`, `PUPPENCLAW_PROJECT_NAME`, `PUPPENCLAW_PROJECT_ROOT`, `PUPPENCLAW_CAMPAIGN_ID`, `PUPPENCLAW_CAMPAIGN_NAME`, `PUPPENCLAW_STEP_ID`, `PUPPENCLAW_STEP_TITLE`, `PUPPENCLAW_TASK` |
| Compute launcher | `LAB_SANDBOX_CONFIG`, and for a job that names a principal `PUPPENCLAW_PRINCIPAL_ID`, `PUPPENCLAW_PRINCIPAL_SOCKET_DIR`, `PUPPENCLAW_PRINCIPAL_SOCKET`; the job's own environment arrives on file descriptor 3 |

`PUPPENCLAW_ORCHESTRATION_ATTEMPT_ID` identifies the turn's attempt; it grants nothing, since the socket itself is the
authority.
